WHAT THE APP DOES
  One offline page for logging gym sessions on two plans that swap every
  two weeks: Heavy Duty (one all-out set per exercise) and Powerbuilding
  (top set + back-offs on squat, bench and deadlift, set by "reps left").
  It opens on today's session, logs reps and weight per set, compares
  with last time, suggests next targets, handles swapped, skipped and
  missed exercises and days, and exports a weekly file.
  No libraries, no network. Works from a saved .html file in a phone browser.

                     layered shadows, motion, 5 multi-colour themes in light and dark), then sections;

                     live bar) is the last section

              checklist? (stretching), rule? (nordic|carry)}
  Exercise ids never change. Heavy Duty: d1-0 ... d5-7 (plus d2-pec, d3-facepull,
  d4-ohcable). Removed ids stay unused: d4-underpd (underhand pushdown), d3-9 (optional
  deadlift, removed 11 October 2026); old logs for them are ignored. Powerbuilding: pb-d1-squat ... pb-d5-sprints, plus pb-dN-warmup
  for each day's warm-up checklist (new, not counted toward progress).

STORAGE KEYS
  localStorage "heavy-duty-tracker-v1": the whole state, JSON. Unchanged key.
  State = the Heavy Duty slot at the top level (exactly the version 1 shape, so
  old saves load untouched) plus:
    cycle {start (Monday, YYYY-MM-DD), first ("hd"|"pb"), lengths [weeks per block, 0 to 12]}   set on first use;
          missing lengths mean two weeks, so older saves load unchanged
    pb    a second slot with the same shape, for powerbuilding
    ui    {tab ("train"|"plan"|"history"), day, openEx, openExtra, theme, mode, cols, helpSeen,
           planView, finder, varOpen, makeupDay, lastOpened, dismissedMiss, histPlan, histWeek, histEx}
  Slot = {weekStart, entries{id: entry}, units{id or id:variant: "kg"|"plates"},
          lastWeek, history, varHistory, loadedStreaks, pastVariations, missedDays, ui{dismissedMiss},
          extras{dayN: [{id, name, unit, sets[], doneAt}]},
          savedSwaps{id: [{name, unit, sets[], date, regular}]}   newest first, at most CONFIG.maxSaved,
          savedExtras{dayN: [{name, unit, sets[], date}]}}       kept per plan and per day, never shared}
  Entry = {sets[{reps, kg, end?, extra?, left?}], variant?, doneAt, replaced,
           repl{name, reason, date, unit?, measure? ("reps"|"time": seconds held|"distance": metres), sets[]}, missed{on, reason, date, madeUp{day,date}?, viaDay?}}
  "reps" holds the main count: reps, metres (carries), minutes (bike),
  rounds (sprints) or "1" for a ticked checklist line. "left" = reps left 0 to 4.
  localStorage "training-tracker-archive": {hd: [week], pb: [week]}, newest first, the last
    CONFIG.archiveWeeks finished weeks per plan. Week = {weekStart, entries (export shape), extras}.
    Filled by Start new week, Load last week and Restore. Not part of the export file.
  localStorage "training-tracker-theme": {palette, mode, contrast, v}. Not part of the export file.
    v 2 (21 October 2026): Tempo became the default theme; a saved "steel" without v moved to Tempo once.
    v 3 (22 October 2026): five themes (pulse default, dune, glacier, forge, bloom); older ids move once
    via themeMove: tempo, volt → pulse; steel, tide, iron → glacier; ember, mono → forge; bush → dune;
    ultraviolet → bloom.
  Offline copy: the browser's Cache Storage, cache "training-tracker-<appVersion>" (sw.js).
  "localStorage-test" is written and removed once to check saving works.

EXPORT FORMAT (unchanged from version 1, with additions)
  File name: workout-week-START-to-END.json (Heavy Duty, as before) or

  {app: "heavy-duty-tracker", version: 2, plan: "hd"|"pb", exportedAt, weekStart, weekEnd,
   entries{id: {plan, day, exercise, rows[], sets[], unit, variant?, doneAt, replaced,
                replacement|null, missed|null}},
   streaks{}, history{}, varHistory{}, variations[], missedDays[{day, title, date, reason,
   total, madeUp[], note}], extras{dayN: [...]},
   backup{lastWeek, history, varHistory, loadedStreaks, pastVariations, missedDays, units,
          savedSwaps, savedExtras, otherPlan: {plan, slot} | null}}
  Version 1 files (no "plan") import as Heavy Duty. Every session is tagged with
